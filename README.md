# Ada Exercises

A collection of exercises and small programs created while learning the Ada programming language.

These exercises cover basic programming concepts such as input and output, variables, conditions, procedures, and simple data processing.

## Exercises

* **Itsas Miliatik Metrora** — Converts nautical miles to meters.
* **Prezio Baxuena** — Processes several prices to determine the lowest values.
* **Satanic Number** — Checks whether a number contains three consecutive `6`s.

## Technologies

* Ada
* GNAT
